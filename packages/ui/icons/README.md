# Icons

The apps' icons are a few of [Lucide](https://lucide.dev)'s, copied from lucide-react 0.574.0 as their SVG shapes
into `../src/icon_paths.ts`, so no icon package is a dependency. `Icon` (`../src/Icon.tsx`) draws one at the size and
colour of the text around it.

Lucide is under the ISC licence (with the parts that come from Feather under MIT); both notices are in `LICENSE`
here and stay with the copied shapes.

To add an icon, copy its shapes from the same Lucide version in the same form and keep the list in order.
Icons go beside words, never instead of them.
